# 飞书桥连

通过飞书机器人远程与 Claude Code 交互。配置完成后，你可以在飞书中直接与 Claude Code 对话，并在 claude-history 中查看所有消息。

## 工作原理

```
飞书消息 → WebSocket (Lark SDK) → FeishuBridge → Claude Code CLI → 飞书卡片回复
                                     ↓
                              JSONL 文件写入
                                     ↓
                           claude-history 刷新可见
```

claude-history 内置了完整的飞书连接能力，使用 Lark SDK 建立 WebSocket 长连接，直接调用本地 Claude Code CLI 处理消息。

### 消息处理流程

1. 用户在飞书发送消息
2. 机器人回复 **敲键盘表情**（Typing reaction），表示正在处理
3. Claude Code CLI 处理请求
4. 处理完成后，移除敲键盘表情，发送结果卡片

如果 Claude 调用了敏感工具（Bash、Write、Edit），会先发送权限确认卡片到飞书，用户点击允许/拒绝后继续执行。

### 权限管控

当 Claude 执行敏感操作时，会暂停并发送确认卡片到飞书。卡片中显示操作详情（命令内容、文件路径、替换内容等），你可以：

- **✅ 允许** — 执行本次操作
- **❌ 拒绝** — 阻止本次操作
- **🔓 始终允许** — 本次及后续所有该工具的调用自动通过

确认卡片有 **60 秒超时**，超时后操作会被自动拒绝。

#### 权限模式

通过 `/permission` 命令切换模式：

| 模式 | 说明 |
|------|------|
| `default` | 敏感工具（Bash、Write、Edit）需要确认 |
| `plan` | 读取类工具自动通过，写入类工具需要确认 |
| `acceptEdits` | 文件编辑自动通过，仅 Bash 需要确认 |
| `bypass` | 所有操作自动通过，不发送确认卡片 |

也可以用 `/allow <工具名>` 单独放行某个工具，例如 `/allow Bash` 后 Bash 命令将不再需要确认。

## 前提条件

- 已安装 Claude Code CLI（`claude` 命令可用）
- 已创建飞书自建应用（在[飞书开放平台](https://open.feishu.cn/)申请）

### 创建飞书应用

1. 访问 [飞书开放平台](https://open.feishu.cn/app) → 创建企业自建应用
2. 记录 **App ID** 和 **App Secret**（在「凭证与基础信息」页面）
3. 在「事件订阅」中启用消息接收事件
4. 在「权限管理」中开通以下权限：
   - `im:message` — 获取与发送单聊、群组消息
   - `im:message.reactions:write_only` — 发送、删除消息表情回复
   - `im:resource` — 读取消息中的资源
5. 在「事件订阅」中注册回调事件：
   - `im.message.receive_v1` — 接收消息
   - `card.action.trigger` — 卡片交互回调（用于权限确认按钮）
6. 发布应用

## 在 claude-history 中配置

### 1. 打开设置

点击 claude-history 中间面板顶部的 **⚙ 设置按钮**（主题切换器旁边）。

### 2. 填写飞书配置

在设置弹窗中：

1. 填入飞书应用的 **App ID**（格式如 `cli_a5f3e2d1b0c4f678`）
2. 填入飞书应用的 **App Secret**
3. 点击 **保存配置**

### 3. 开启桥连

配置保存后，打开 **飞书桥连** 开关。应用会自动：

- 使用 Lark SDK 建立 WebSocket 连接到飞书
- 开始监听飞书消息
- 应用下次启动时自动重连

开关打开后，按钮变为绿色，表示桥连已启用。

## 飞书端操作

### 发送消息

在飞书中直接给机器人发送消息即可与 Claude Code 对话。第一条消息需要先在 claude-history 中绑定一个会话。

### 斜杠命令

claude-history 内置了丰富的命令系统，支持中英文双语命令：

#### 基础命令

| 命令 | 中文别名 | 说明 |
|------|----------|------|
| `/help` | `/帮助` | 显示所有可用命令 |
| `/status` | `/状态` | 查看连接状态和绑定信息 |
| `/bind` | — | 查看当前绑定详情 |
| `/cancel` | `/取消` | 取消正在处理的任务 |

#### 会话管理

| 命令 | 中文别名 | 说明 |
|------|----------|------|
| `/new` 或 `/clear` | — | 开启全新会话 |
| `/sessions` | `/会话` | 列出当前项目的所有会话 |
| `/switch <序号或ID>` | — | 切换到指定会话 |
| `/history [n]` | `/历史 [n]` | 查看最近 n 条消息（默认 5） |
| `/repeat` | — | 重新发送上一条消息 |

#### 环境配置

| 命令 | 说明 |
|------|------|
| `/cd <路径>` | 切换工作目录（支持 `~` 和相对路径） |
| `/model [名称]` | 查看或设置 Claude 模型（`sonnet` / `opus` / `haiku`） |
| `/system <提示>` | 发送系统提示给 Claude |
| `/confirm [on\|off]` | 开启/关闭执行确认模式 |
| `/permission [mode]` | 查看或设置权限模式（`default` / `plan` / `acceptEdits` / `bypass`） |
| `/allow <工具>` | 始终允许指定工具（如 `/allow Bash`） |
| `/disallow <工具>` | 取消工具的始终允许 |

### @机器人触发

在群聊中，需要先 **@机器人** 再输入命令或消息，机器人才会响应。私聊中直接发送即可。

### 绑定已有会话

在 claude-history 的对话详情页，点击 **「绑定到飞书」** 按钮（在「恢复会话」按钮旁边），应用会自动：

1. 读取该对话的 session ID（JSONL 文件名去掉 `.jsonl`）
2. 创建绑定记录
3. 飞书端下次发消息时自动关联

绑定后，飞书发送的消息会使用 `claude --resume <session-id>` 继续该会话。

> **前提**：飞书桥连开关必须已打开（设置按钮显示绿色）。

## 在 claude-history 中查看

桥连启用后，claude-history 会展示以下信息：

- **对话列表圆点**：有远程会话的对话前会显示状态圆点
  - 🟢 绿色脉动 = 远程会话活跃中
  - 🟡 黄色 = 远程会话空闲
- **消息来源标签**：通过飞书发送的消息气泡上会标注「🐦 来自飞书」
- **远程状态标签**：消息详情顶部显示「飞书 活跃」或「飞书 空闲」

### 查看最新内容

飞书端有新消息后，点击 claude-history 顶部的 **刷新按钮** 即可看到最新内容。或者切换到其他对话再切回来。

## 设置弹窗说明

| 区域 | 功能 |
|------|------|
| 飞书桥连开关 | 开启/关闭桥连功能 |
| App ID | 飞书应用凭证 ID |
| App Secret | 飞书应用密钥 |
| 连接状态 | 显示当前桥连状态（运行中 / 未连接 / 配置错误） |
| 绑定信息 | 当前绑定的会话 ID、Chat ID 等 |
| 使用说明 | 操作指引 |

## 数据存储

飞书桥连的配置和绑定信息存储在 claude-history 的 SQLite 数据库中（`~/.claude/history-viewer.db`）：

- `feishu_config` 表 — 存储 App ID、启用状态等
- `feishu_bindings` 表 — 存储会话绑定关系

> **安全说明**：App Secret 使用 Electron safeStorage 加密存储在本地数据库中，不会上传到任何服务器。

## 常见问题

### 设置按钮没有变绿

检查以下几点：

1. **App ID / Secret 未填写**：必须先填写配置才能开启桥连
2. **飞书应用未发布**：需要在飞书开放平台发布应用
3. **权限不足**：确认已开通 `im:message:receive_v1` 和 `im:message:send_v1` 权限
4. **连接失败**：查看终端输出的错误日志

### 飞书消息没有出现在 claude-history 中

1. 确认桥连开关已打开（设置按钮为绿色）
2. 点击顶部的刷新按钮更新对话列表
3. 确认已绑定会话（未绑定时飞书会提示"未绑定会话"）

### 对话列表中没有圆点

圆点需要桥连已连接且有活跃会话时才会显示。如果刚刚开始对话，点击刷新按钮更新状态。

### 飞书中提示"未绑定会话"

说明当前飞书聊天没有绑定到 Claude Code 会话。请在 claude-history 桌面端的对话详情页点击「绑定到飞书」按钮。

### 如何关闭桥连

打开设置弹窗，关闭「飞书桥连」开关即可。这会断开 WebSocket 连接。下次启动应用时不会自动连接。

### /cd 命令切换目录后自动创建了新会话

这是预期行为。切换工作目录后，Claude Code 需要在新目录下创建新的 JSONL 文件。

### 支持同时绑定多个飞书聊天吗

当前版本支持一个活跃绑定。如需切换，请先解绑再重新绑定。

### 权限确认卡片没有出现

1. 确认权限模式不是 `bypass`（用 `/status` 查看）
2. 确认飞书应用已开通 `card.action.trigger` 事件回调
3. 确认 Claude 使用了 `--settings` 参数启用了 hook（正常流程会自动启用）

### 如何跳过权限确认

使用 `/permission bypass` 切换到全自动模式，或用 `/allow Bash` 等命令单独放行特定工具。
